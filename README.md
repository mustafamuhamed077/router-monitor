# Router Monitor

A Windows app that monitors your home router usage — it signs in to your router locally and shows usage readings over time.

## ⬇️ Download

[**Download RouterMonitor.exe**](https://github.com/mustafamuhamed077/router-monitor/releases/download/v1.0/RouterMonitor.exe)

## How to use

1. Download the exe and run it on Windows
2. Sign in with the same username and password you use on your router page
3. Your credentials are sent to your router only and never leave your local network
